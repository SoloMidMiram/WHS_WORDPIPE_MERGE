# NCM-assisted Flowers context pilot

This experiment compares original passages, deterministic extraction, and NCM-assisted digestion. It follows [WHS #8](https://github.com/SoloMidMiram/WHS_WORDPIPE_MERGE/issues/8) and [WHS #9](https://github.com/SoloMidMiram/WHS_WORDPIPE_MERGE/issues/9), with related [A2A #40](https://github.com/SoloMidMiram/md-mdc-Agents-Skills-MCPs-Kagent-A2A-SubAgents/issues/40) and [A2A #41](https://github.com/SoloMidMiram/md-mdc-Agents-Skills-MCPs-Kagent-A2A-SubAgents/issues/41).

The checked-in examples are independently authored synthetic Markdown-style cases. Their annotations were written before running any comparison and have no second-reviewer validation. Source IDs and exact constraints accompany generated prose, which remains derived evidence. No private research text, source-derived records, checkpoints, or dependency artifacts belong in this branch.

Gate A is blocked on the previously observed native ABI and installer-trust findings. Local NCM inference requires Gate A and then an isolated, restricted checkpoint load. The synthetic smoke must pass before any local Flowers subset is presented to the worker. The deterministic comparison can proceed independently. All paths are opt-in and canonical Chronicle outputs are outside the experiment.
