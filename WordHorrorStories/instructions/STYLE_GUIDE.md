# Style Guide — ChatGPT Chronicle (Court Transcript)

Headings:
  # Title
  ## Part N — Era title
  ### Exhibit P{N}-X — Lens/title
  ### Footnotes (end of Part)
  ## Appendices
  ### Appendix A — Source coverage
  ### Appendix B — Event index
  ### Appendix C — Link registry

Clerk's note format:
  Clerk's note: ...
  Clerk's note (hearsay): ...
  Clerk's note (citation missing): ...

Dates:
  Prefer explicit dates when present.
  If only month known: "June 2025 (approx.)"

Lists:
  Preserve original list structure.
  Do not convert bullets into paragraphs.

Citations:
  Replace inline URL with footnote marker.
  Footnote format:
    [^P3-01]: Short descriptor — https://example.com
